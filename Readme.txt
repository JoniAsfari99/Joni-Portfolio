# Joni Asfari — Personal Portfolio

Welcome to my personal portfolio repository!

This project showcases my professional profile, skills, work experience, and selected projects through a responsive website built using HTML, CSS, and JavaScript.

## 🌐 Live Website

**[View My Portfolio](https://joniasfari99.github.io/Joni-Portfolio/)**

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📌 Features

* Personal introduction and professional profile
* Work experience and education
* Skills and expertise
* Selected projects and industry experience
* Contact information
* Responsive layout for desktop and mobile devices

## 🚀 Getting Started

To run this project locally:

1. Clone this repository:
   `git clone https://github.com/joniasfari99/Joni-Portfolio.git`
2. Open the project folder.
3. Open `index.html` in your web browser.
